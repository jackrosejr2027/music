COMPLETE OFFLINE VERSION

Extract offllinecodebbase.zip with all folders intact.
With Python installed, run python -m http.server 8000 in the extracted folder,
then open http://localhost:8000/index.html. No internet is required.
Direct file:// opening is not supported reliably by browsers.

For a hosted install, open the app online and wait for the offline-ready notice
before disconnecting. Browser storage must remain available and must not be cleared.

The ZIP omits itself and its static download link to avoid recursive archives.
The extracted offline manifest lists only the files included in the archive.
To create another package locally, use the offline ZIP button in Release Notes.
